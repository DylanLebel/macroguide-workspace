Getting Started with Macros

Everything you need to know to start using SolidWorks macros at Nordic Minesteel. Whether you're brand new or just need a refresher.

🤔 What is a macro?

A macro is a small program that runs inside SolidWorks. Instead of manually clicking through menus, typing in property values, creating PDFs, or repeating the same 20 steps for every file — you press one button and the macro does it all instantly.

Every macro on this site was built specifically for Nordic Minesteel's workflow. They know our PDM vault, our folder structures, our property names, our templates, and our manufacturing limits. They're not generic tools — they're custom-built for how we work.

⚡ The #1 rule: Check out your files first

If the file isn't checked out in PDM, the macro can't save changes. This is the most common mistake.

Before running any macro that modifies properties (Prepare for CADLink, Move to PDM, Date Fixer, etc.), make sure the file is checked out to you in PDM. If it's checked in, the macro will run and everything might look fine — but when you close the file, all the changes disappear.

Remember: Checked out = changes save. Checked in = changes vanish. Check the lock icon in PDM before running.

▶️ How to run a macro

If Dylan has already set up your computer, you'll have macro buttons in your SolidWorks toolbar — just click and go. That's the easiest way. If you don't see them, ask Dylan to set them up (takes 2 minutes).

Running manually (if no toolbar button):

1

In SolidWorks, go to Tools → Macro → Run in the top menu bar.

2

Browse to C:\AllMacros\ (or the Y: drive macro folder) and find the .swp file for the macro you want.

3

Click Open. The macro starts immediately.

🔧 Adding a macro to your toolbar (one-time setup)

This puts a permanent button in your SolidWorks toolbar so you never have to browse for the file again.

1

In SolidWorks, right-click any toolbar and choose Customize…

2

Go to the Commands tab. In the categories list, find Macros.

3

Drag the New Macro Button onto any toolbar where you want it.

4

A dialog opens — browse to the macro file (.swp), pick an icon, and give it a name. Click OK.

5

Done! One click to run it from now on.

Easier option: Just ask Dylan to set it up for you — it takes one minute and he can add all the macros you need at once.

📋 Which macro do I need?

I need to get a model ready for CADLink
Prepare for CADLink — the main one. Check out the model, run it, fill in anything it flags as red (Revision, Product Group), done. Works on single parts or entire assemblies.
I need to create PDFs from drawings
PDM PDF Generator — run it from a single drawing, an assembly (creates PDFs for everything), or batch-process a whole folder. Also has an audit mode to check what's missing.
I need to create a DXF burn profile
PDM DXF Exporter — select the flat face you want to cut, run the macro. Be careful to pick the right face (watch out for counter-sinks).
I need to clean up properties for PDM
Move to PDM — talk to Dylan first. The rules need to be configured for your specific batch of files. It's powerful but needs setup.
I need to convert metric models to imperial
Model to Imperial — open the part or assembly, run it. Converts everything including sub-parts automatically.

⚠️ Troubleshooting

The macro runs but nothing seems to happen
Make sure the right type of file is open — each macro needs a specific type (part, assembly, or drawing). Check the macro's page in this guide for what it expects. Also make sure the file is checked out.
Properties filled in but disappeared after closing
The file wasn't checked out. Check it out in PDM, run the macro again, and the changes will stick this time.
SolidWorks shows a security warning
Click "Enable macros" — all macros here are written in-house by Dylan and are safe to run.
The macro gave an unexpected result
Use Ctrl+Z (undo) — most changes can be undone. Then submit a bug report in the Requests tab so Dylan can investigate.
A macro is missing or broken
The file may have been updated or moved. Contact Dylan directly — he can fix it in minutes.
Can I break something by running a macro?
Generally no — PDM keeps full version history so nothing is ever truly lost. But for batch operations (processing hundreds of files), always check with Dylan first if you're not sure about the settings.
