Getting Started with Macros

New to the team? This guide gets you up and running with SolidWorks macros in minutes.

🤔 What is a macro?

A macro is a small program that runs inside SolidWorks and handles repetitive tasks automatically. Instead of clicking through menus and filling in fields by hand — which takes time and causes mistakes — you press a button and the macro does it instantly.

Think of it like a supercharged shortcut that can do dozens of steps at once.

▶️ How to run a macro

If Dylan has already set up your computer, you'll have macro buttons in your SolidWorks toolbar — just click and go. If your machine is new or not set up yet, contact Dylan.

Running manually (no toolbar button):

1

In SolidWorks, go to Tools → Macro → Run in the top menu bar.

2

A file browser opens. Navigate to the macro folder on your computer and find the .swp file for the macro you want.

3

Click Open. The macro starts immediately.

🔧 Adding a macro to your SolidWorks toolbar (one-time setup)

1

In SolidWorks, right-click any toolbar and choose Customize…

2

Go to the Commands tab. In the categories list, find Macros.

3

Drag the New Macro Button onto any toolbar.

4

A dialog opens — browse to the macro file (.swp), pick an icon, and give it a label. Click OK.

5

Your macro button is now in the toolbar. One click to run it every time.

Tip: Ask Dylan to do this for you — it only takes a minute and saves you from navigating menus every time.

⚠️ Common issues & questions

The macro runs but nothing seems to happen
Most macros need the right type of file open first. Make sure the correct part, assembly, or drawing is open before running. Each macro's page in this guide lists what it needs.
SolidWorks shows a security warning when I run a macro
This is normal. Click "Enable macros" or similar — all macros here are written in-house and are safe to run.
The macro gave an unexpected result or something looks wrong
Use Ctrl+Z (undo) — most macro changes can be undone. Then submit a bug report in the Requests tab so Dylan can look into it.
A macro that used to work is now broken or missing
The macro file may have moved or been updated. Contact Dylan directly — he maintains all macros and can get you sorted quickly.
Can I break something by running a macro?
In most cases, no — especially since PDM keeps a history. But for batch operations that modify many files, always check with Dylan before running if you're unsure. When in doubt, ask first.
